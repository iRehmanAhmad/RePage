# Product Roadmap

The roadmap describes outcome order, not calendar promises. Dates should be added only after the Foundation milestone establishes team capacity and technical risk.

## M0 — Foundation and risk elimination (COMPLETE)

Outcome: trustworthy UTF-8 data, canonical document model, tests, autosave, and package round trips.

Primary gate: a two-page Urdu document survives edit, close, recovery, save, and reopen without changing content or geometry.

## M1 — Local page-layout alpha (COMPLETE)

Outcome: a user can create a useful Urdu poster, letterhead, poetry page, or simple newspaper page entirely offline.

Includes multi-page navigation, text/image/shape frames, layers, inspector, rulers, guides, snapping, undo/redo, templates, PNG export, and honest raster PDF export.

## M2 — Urdu typography beta (COMPLETE)

Outcome: reliable professional text editing for common Urdu publishing workflows.

Includes mixed RTL/LTR editing, character and paragraph styles, vetted fonts, bidi controls, columns, find/replace, keyboard modes, glyph-clipping protection, and typography regression fixtures.

## M3 — Document production beta (COMPLETE)

Outcome: documents can be prepared predictably for printers and long-form layout.

Includes linked text frames, master pages, page numbering, reusable styles, bleed, crop marks, preflight, asset relinking, package-for-print, and production PDF export.

## M4 — Cross-platform desktop release candidate (COMPLETE)

Outcome: signed, installable, updateable Windows, macOS, and Linux applications.

Includes Tauri packaging, native file dialogs, recent files, crash recovery, platform shortcuts, installer testing, accessibility review, telemetry opt-in decision, and signed update strategy.

## M5 — Collaboration preview (COMPLETE)

Outcome: two to four invited editors can safely collaborate without compromising local ownership.

Includes Yjs synchronization, presence, comments, identity, invitations, roles, signaling, TURN fallback, offline reconciliation, and optional durable remote storage.

## M6 — Professional ecosystem

Outcome: extensible workflows for publishers, newspapers, educators, authors, and design teams.

Candidates include DOCX/RTF import, legacy-format research, dictionaries, Urdu spellchecking, OCR, transliteration, organisational templates, review/version history, plugins, and automation APIs.

## Explicitly deferred

- General-purpose spreadsheet or presentation editing.
- Full Microsoft Word parity.
- Large-room audio/video conferencing.
- Unverified legacy InPage binary import.
- Bundling proprietary Urdu fonts.
- Mobile-phone-first professional layout editing.
