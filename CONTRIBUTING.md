# Contributing

UrduPage is in a pre-foundation stage. Contributions should improve the documented milestone rather than expand the prototype horizontally.

## Before contributing

Read `AGENTS.md`, `MEMORY.md`, `PROJECT_STATUS.md`, and the relevant specification. For substantial work, begin from the work-item template in `docs/templates/WORK_ITEM.md`.

## Contribution priorities

1. UTF-8 repair and Urdu fixtures.
2. Canonical TypeScript document model.
3. Validation, tests, autosave, and safe package handling.
4. Canvas and text adapters around the canonical model.
5. Typography and export reliability.

Unrequested audio, AI, cloud, and collaboration expansion should wait for their roadmap milestones.

## Pull-request expectations

- Explain the problem and user outcome.
- State verification performed.
- Identify document-format or migration impact.
- Include before/after visuals for layout changes.
- Include Urdu/mixed-bidi fixtures when typography is affected.
- Update status, memory, ADRs, and specifications as required by `AGENTS.md`.
- Avoid drive-by formatting or unrelated dependency upgrades.

## Licensing

The project licence has not yet been selected. Do not submit copied code, proprietary fonts, calligraphy, templates, or other assets without documented redistribution rights and provenance.
