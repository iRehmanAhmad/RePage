# Work Item: M4.3 Desktop Integration & Native OS Services

Status: Approved  
Milestone: M4 (Cross-Platform Desktop Release Candidate)  
Owner: Core Architecture Team  

## User outcome

Deep desktop OS integration including window title dirty state tracking, native menu shortcuts (`Ctrl+O`, `Ctrl+S`, `Ctrl+P`), system clipboard API, native print dialog trigger, OS dark/light theme detection, High-DPI screen scaling support, and screen-reader accessibility ARIA live regions.

## Scope

### Included

- **Window Title & Dirty Indicator (`src/platform/tauri/windowIntegration.ts`)**:
  - Dynamically formats title `${title}${isDirty ? ' *' : ''} — RePage` and sets OS edited state.
- **Native Clipboard API (`src/platform/clipboard.ts`)**:
  - Native and browser clipboard copy/paste integration.
- **Native Print Service (`src/platform/printService.ts`)**:
  - Native print dialog execution (`window.print()`).
- **OS Theme Integration (`src/ui/theme/themeIntegration.ts`)**:
  - Media query listener for system dark/light theme changes (`prefers-color-scheme`).
- **High-DPI Canvas Scaling & Accessibility (`src/ui/common/accessibility.ts`)**:
  - Device pixel ratio backing store adjustment & ARIA live region status announcer.
- **Unit Tests (`src/platform/desktopIntegration.test.ts`)**:
  - Unit test coverage for title formatting, dirty indicator, theme detection, and clipboard helpers.
