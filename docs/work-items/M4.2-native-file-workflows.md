# Work Item: M4.2 Native File Workflows & File Associations

Status: Approved  
Milestone: M4 (Cross-Platform Desktop Release Candidate)  
Owner: Core Architecture Team  

## User outcome

Seamless native file workflows for `.urdup` packages including Open, Save, Save As, atomic file replacement (to prevent corruption), recent files history, file drag-and-drop onto workspace, and external file modification conflict detection.

## Scope

### Included

- **File Workflow Engine (`src/persistence/package/fileWorkflowEngine.ts`)**:
  - `DocumentFileRef` tracking open path, dirty status, and file modification timestamp.
  - `atomicSavePackage`: Writes to `.urdup.tmp` before renaming/moving to target path.
- **Recent Files Management (`src/persistence/package/recentFiles.ts`)**:
  - Stores up to 10 recent documents (`title`, `path`, `openedAt`) with persistence.
- **External Modification Conflict Detector (`src/persistence/package/conflictDetector.ts`)**:
  - Compares last-known file mtime with active disk mtime to trigger user warning banner.
- **File Associations (`src-tauri/tauri.conf.json`)**:
  - Configured `.urdup` package file association for desktop OS double-click launch.
- **Drag-and-Drop Handler (`src/ui/common/DragAndDropOverlay.tsx`)**:
  - Visual drag-and-drop zone handling dropped `.urdup` files.
- **Unit Tests (`src/persistence/package/fileWorkflowEngine.test.ts`)**:
  - Verification of atomic save, recent files store, and conflict detection.

## Verification
