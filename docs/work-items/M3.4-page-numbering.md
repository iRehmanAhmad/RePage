# Work Item: M3.4 Automatic Page Numbering & Urdu Numerals

Status: Approved  
Milestone: M3 (Document Production Beta)  
Owner: Core Architecture Team  

## User outcome

Dynamic page numbering fields for document pages supporting Eastern Arabic / Urdu numerals (`۰-۹`), Western numerals (`0-9`), section offsets, custom start numbers, prefixes, suffixes, and Master Page header template token replacement (`{{pageNumber}}`, `{{totalPages}}`).

## Problem and evidence

Urdu books, magazines, and newspapers require authentic Eastern Arabic / Urdu numerals (`صفحہ ۱۲`, `صفحہ ۲۴`) integrated into running headers/footers on Master Pages.

## Scope

### Included

- **Page Numbering Engine (`src/domain/unicode/pageNumbering.ts`)**:
  - `toUrduNumerals(num)`: Converts Western ASCII digits to Eastern Arabic digits (`\u06F0` - `\u06F9`).
  - `formatPageNumber(pageIndex, options)`: Formats page number with style (`urdu` | `western` | `abjad`), start number, section offset, prefix, suffix.
  - `resolvePageNumberTokens(template, pageIndex, totalPages, options)`: Replaces `{{pageNumber}}`, `{{totalPages}}` tokens.
- **Unit Tests (`src/domain/unicode/pageNumbering.test.ts`)**:
  - Full test coverage for digit conversion, numeral styles, token replacement, and master page integration.

### Excluded

- Dynamic table of contents generation (deferred to M3.8).

## Acceptance criteria

- [x] `toUrduNumerals` maps `0-9` to `۰-۹` correctly.
- [x] `formatPageNumber` with `'urdu'` style renders Eastern Arabic digits with prefixes and suffixes.
- [x] `resolvePageNumberTokens` resolves `{{pageNumber}}` and `{{totalPages}}` dynamically.

## Verification

- Unit tests in `pageNumbering.test.ts`.
- `npm run check` pipeline execution.
