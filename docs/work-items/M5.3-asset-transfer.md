# Work Item: M5.3 Collaborative Asset Transfer & Durable Storage

Status: Approved  
Milestone: M5 (Collaboration Preview)  
Owner: Core Architecture Team  

## User outcome

Resumable, rate-limited, content-addressed asset transfer pipeline for multi-user collaboration, storing binary images outside Yjs maps while rendering missing-asset placeholders until complete transfer.

## Scope

### Included

- **Asset Transfer Engine (`src/collaboration/assetTransferEngine.ts`)**:
  - SHA-256 hash content-addressing for images and media assets.
  - **Inviolable Invariant**: Image binaries are NEVER stored in Yjs maps; only lightweight asset metadata (`{ id, hash, size, mimeType }`) is synced via CRDT.
  - Dedicated resumable chunked transfer pipeline (`AssetTransferQueue`).
  - Size limit enforcement (Max 50 MB) and rate limiting (Max 5 MB/s).
  - Missing-asset status tracking (`'available' | 'transferring' | 'missing' | 'failed'`).
  - Retry logic with exponential backoff for interrupted uploads/downloads.
- **Durable Storage Architecture**:
  - Local persistence: IndexedDB (browser) / `assets/` package directory (Tauri desktop).
  - Remote persistence: Presigned object storage URLs.
