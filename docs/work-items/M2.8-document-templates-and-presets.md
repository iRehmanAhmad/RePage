# Work Item: M2.8 Urdu Document Templates & Preset Layouts

Status: Approved  
Milestone: M2 / M3 Document Production  
Owner: Core Architecture Team  

## User outcome

Users can instantly create professional Urdu documents from pre-built layout templates (Newspaper Page, Poetry Book, Letterhead, Poster/Flyer) populated with valid Urdu text frames, shapes, stories, and styles.

## Problem and evidence

Creating complex multi-column Urdu layouts from scratch takes time. RePage requires built-in layout templates for common publishing workflows.

## Scope

### Included

- **Template Engine (`src/domain/templates/documentTemplates.ts`)**:
  - `DocumentTemplate` interface and factory function `createDocumentFromTemplate(templateId, title)`.
  - Built-in templates:
    1. **Urdu Newspaper Page (`اخبار صفحہ`)**: 3-column layout with headline story and sidebar.
    2. **Urdu Poetry Book (`دیوان / شاعری کتاب`)**: 2-page A5 spread with centered poetry couplet frames.
    3. **Urdu Letterhead (`لیٹر ہیڈ`)**: A4 layout with header block, contact details, and story frame.
    4. **Urdu Poster / Flyer (`اشتہار / پوسٹر`)**: Poster layout with large Nastalique title and image frame.
- **Unit Tests (`src/domain/templates/documentTemplates.test.ts`)**:
  - Verify all templates produce validated schema-v1 documents (`parseDocument`).

### Excluded

- Downloading remote binary templates (all templates are self-contained code-defined presets).

## Acceptance criteria

- [x] All 4 templates generate valid schema-v1 `RePageDocument` instances.
- [x] Template documents pass Zod validation and `.urdup` package serialization.

## Verification

- Unit tests in `documentTemplates.test.ts`.
- `npm run check` pipeline execution.
