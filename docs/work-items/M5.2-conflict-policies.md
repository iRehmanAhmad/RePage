# Work Item: M5.2 Collaborative Conflict Policies & Undo Invariants

Status: Approved  
Milestone: M5 (Collaboration Preview)  
Owner: Core Architecture Team  

## User outcome

Deterministic conflict resolution and scoped local undo semantics during concurrent multi-user editing sessions, guaranteeing document state convergence and crash-free operation.

## Scope

### Included

- **Conflict Engine (`src/collaboration/conflictEngine.ts`)**:
  - **Concurrent Movement**: Last-Writer-Wins (LWW) transaction ordering preserving frame boundaries.
  - **Concurrent Resize**: LWW width/height resolution enforcing minimum frame bounds (`10pt`).
  - **Delete vs Edit**: Deletion takes precedence; pending edits on deleted objects are dropped.
  - **Page Delete vs Object Edit**: Deleting a page cascades to all child objects; edits targeting deleted pages drop safely.
  - **Style Deletion in Use**: Replacing deleted styles with default fallback (`default-paragraph-style`).
  - **Linked-Story Reflow**: Deterministic multi-frame text reflow recomputation.
  - **Scoped Local Undo**: Uses `Y.UndoManager` tied to local transaction origin (`trackedOrigins`), ensuring local `Ctrl+Z` undoes only local mutations.
