# Work Item: M3.8 Table of Contents & Long Document Automation Engine

Status: Approved  
Milestone: M3 (Document Production Beta)  
Owner: Core Architecture Team  

## User outcome

Automated Table of Contents (`فہرست مضامین`) generation scanning headline/subheading paragraph styles across document pages, dynamic running header resolution by active section heading, and formatted TOC rich text story creation with Urdu numerals (`صفحہ ۱`, `صفحہ ۵`).

## Problem and evidence

Long document publishing (books, digests, magazines) requires automatic Table of Contents generation and dynamic section running headers updated as pages reflow.

## Scope

### Included

- **TOC & Section Automation Engine (`src/domain/document/tocEngine.ts`)**:
  - `generateTableOfContents(doc, options)`: Scans heading paragraph styles and maps title \(\rightarrow\) page number.
  - `generateRunningHeaderForPage(doc, pageId, targetStyleId)`: Extracts active section header text for running header frames.
  - `buildTocTextStoryContent(entries, options)`: Formats TOC entries into a canonical `RichTextDocument`.
- **Unit Tests (`src/domain/document/tocEngine.test.ts`)**:
  - Verification of TOC entry extraction, Urdu page number formatting, and running header text resolution.

### Excluded

- Interactive PDF hyperlinked annotations (deferred to M4).

## Acceptance criteria

- [x] `generateTableOfContents` extracts section headings and maps correct page indices.
- [x] `generateRunningHeaderForPage` resolves current active section header for target page.
- [x] `buildTocTextStoryContent` constructs valid `RichTextDocument` with tab dots / leaders.

## Verification

- Unit tests in `tocEngine.test.ts`.
- `npm run check` pipeline execution.
