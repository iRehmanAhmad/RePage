# Work Item: M5.1 CRDT Mapping & Awareness Protocol

Status: Approved  
Milestone: M5 (Collaboration Preview)  
Owner: Core Architecture Team  

## User outcome

Collaborative real-time editing using Yjs CRDT shared maps for canonical document entities (page order, pages, objects, stories, styles, comments), while isolating ephemeral user presence (cursor, selection, active page, display name, user color) inside Yjs Awareness protocol.

## Scope

### Included

- **CRDT Document Binder (`src/collaboration/crdtDoc.ts`)**:
  - Maps `RePageDocument` entities to Yjs shared maps (`yPageOrder`, `yPages`, `yObjects`, `yStories`, `yStyles`, `yComments`).
  - Binary asset exclusion: Asset binaries are stored in persistent Blob/SHA-256 storage and referenced by ID, keeping Yjs shared maps lightweight.
  - Bidirectional translation functions (`canonicalToYjsDoc` and `yjsToCanonicalDoc`).
- **Awareness Manager (`src/collaboration/awareness.ts`)**:
  - Isolated ephemeral presence protocol (`CollaboratorPresence`) tracking user ID, display name, user color, active page, selection, and canvas cursor.
- **Unit Tests (`src/collaboration/crdtDoc.test.ts`)**:
  - Full round-trip verification between canonical `RePageDocument` and Yjs `Y.Doc`.
