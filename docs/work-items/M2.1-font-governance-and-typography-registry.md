# Work Item: M2.1 Font Governance and Typography Registry

Status: Approved  
Milestone: M2 (Urdu Typography Beta)  
Owner: Core Architecture Team  

## User outcome

Users can render, format, and preview text frames with verified OFL-licensed Urdu fonts (Noto Nastaliq Urdu, Gulzar, Noto Naskh Arabic) with deterministic font loading, font fallbacks, and font registry metadata.

## Problem and evidence

Typography is the defining capability of RePage. Without an explicit font registry, text rendering relies on browser defaults or unverified local fonts, leading to metric mismatches, glyph clipping, or unvalidated font licensing.

## Scope

### Included

- Define `FontRegistry` metadata for OFL-licensed Urdu fonts (Noto Nastaliq Urdu, Gulzar, Noto Naskh Arabic) and system fallbacks.
- Web font loading and `@font-face` rules in `index.css`.
- Asynchronous font loading detection helper `ensureFontsLoaded()` using `document.fonts`.
- Font substitution rules and fallback chains.
- Unit tests for font lookup, fallback chain resolution, and metadata compliance.

### Excluded

- Proprietary font file redistribution without documented license rights (e.g. InPage Jameel Noori binaries).

## Compatibility impact

- **Document schema/migration**: No schema version change required.
- **Autosave/recovery**: Pure metadata & styling.
- **Urdu/bidi/fonts**: Guarantees deterministic font loading before canvas measurement.
