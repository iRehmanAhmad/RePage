# Work Item: M2.7 Urdu Character & Paragraph Styles, Column Layouts & Find/Replace

Status: Approved  
Milestone: M2 (Urdu Typography Beta) / M3  
Owner: Core Architecture Team  

## User outcome

Users can apply reusable Urdu character and paragraph styles (Headline, Subheading, Body Text, Poetry Couplet), configure multi-column text frame layouts, and perform case/aerab-aware Urdu Find & Replace across document stories.

## Problem and evidence

Publishing newspapers, magazines, and books in Urdu requires consistent typography presets, multi-column page columns, and text search/replace across document stories.

## Scope

### Included

- **Character & Paragraph Styles (`src/domain/rich-text/styles.ts`)**:
  - Reusable style definitions (`ParagraphStyle`, `CharacterStyle`).
  - Standard Urdu presets (`Urdu Headline`, `Urdu Subheading`, `Urdu Body Text`, `Poetry Couplet`).
  - Style application commands and Zod validation.
- **Multi-Column Frame Layouts (`types.ts`, `schema.ts`, `fabricAdapter.ts`)**:
  - `columns?: number` and `columnGap?: number` on `TextFrameObject`.
- **Urdu Find & Replace Engine (`src/domain/rich-text/findReplace.ts`)**:
  - `findInText(text, query, options)` supporting Aerab-insensitive diacritic search.
  - `replaceInText(text, query, replacement)` and `replaceAllInText`.
- Unit tests in `src/domain/rich-text/styles.test.ts` and `src/domain/rich-text/findReplace.test.ts`.

### Excluded

- External grep regex engines.

## Acceptance criteria

- [x] Preset Urdu Paragraph Styles apply to story documents cleanly.
- [x] Multi-column frame properties validate in `schema.ts`.
- [x] Find & Replace locates and substitutes Urdu text phrases correctly with/without diacritics.

## Verification

- Unit tests in `styles.test.ts` and `findReplace.test.ts`.
- `npm run check` pipeline execution.
