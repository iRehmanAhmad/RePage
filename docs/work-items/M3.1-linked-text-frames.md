# Work Item: M3.1 Linked Text Frames & Multi-Page Story Reflow

Status: Approved  
Milestone: M3 (Document Production Beta)  
Owner: Core Architecture Team  

## User outcome

Users can link text frames across multiple columns and pages (`sourceFrame` \(\rightarrow\) `targetFrame`) with circular-link prevention, automatic text overflow reflow across frame sequences, visual link badges, and safe frame deletion preserving story content.

## Problem and evidence

Publishing long Urdu publications (newspapers, magazines, books) requires text flowing seamlessly across linked text frames on multiple pages without circular link bugs or accidental story deletion.

## Scope

### Included

- **Story-to-Frame Linked Engine (`src/domain/document/textFlowEngine.ts`)**:
  - `linkTextFrames(doc, sourceId, targetId)` with strict circular-link detection.
  - `unlinkTextFrame(doc, frameId)` for unlinking frame segments.
  - `deleteTextFramePreservingStory(doc, frameId)` ensuring story text persists when a frame is removed.
  - `reflowStoryContent(doc, storyId)` distributing story content across frame chains.
  - `preventCircularLinks(doc, sourceId, targetId)` validation.
- **Visual Link Connectors & Sequence Badges**:
  - Visual frame sequence index badges (`[1]`, `[2]`, `[3]`) in `fabricAdapter.ts`.
- **Unit Tests (`src/domain/document/textFlowEngine.test.ts`)**:
  - Verification of circular link rejection, story retention during frame deletion, and multi-page text reflow.

### Excluded

- Operating-system level native print drivers.

## Acceptance criteria

- [x] Circular frame linking attempts are detected and rejected.
- [x] Deleting a text frame preserves the canonical `TextStory` in `doc.stories`.
- [x] Multi-frame story reflow updates sequence order and sets `overflow` on oversetting final frames.

## Verification

- Unit tests in `textFlowEngine.test.ts`.
- `npm run check` pipeline execution.
