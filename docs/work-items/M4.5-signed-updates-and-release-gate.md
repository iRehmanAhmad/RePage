# Work Item: M4.5 Signed Updates, Rollback Policy & Release Exit Gate

Status: Approved  
Milestone: M4 (Cross-Platform Desktop Release Candidate)  
Owner: Core Architecture Team  

## User outcome

Secure signed update manifest verification, stable and beta release channels, failed-update rollback recovery, explicit document migration controls (never invisible), and complete M4 release exit gate validation across all desktop operating systems.

## Scope

### Included

- **Update Manager Engine (`src/platform/tauri/updateManager.ts`)**:
  - Signed update manifest validation (`version`, `pub_date`, `signature`).
  - Stable and Beta release channel support.
  - Failed-update recovery & rollback policy definition.
  - **Inviolable Invariant**: Document migrations are NEVER executed invisibly during background application updates.
- **Tauri Updater Configuration (`src-tauri/tauri.conf.json`)**:
  - Configured updater plugin schema with public key verification.
- **M4 Release Exit Gate Suite (`src/platform/m4ExitGate.test.ts`)**:
  - Comprehensive unit test suite verifying update manifests, channels, rollback policies, and typography tolerance limits.
- **Release Exit Gate Report (`docs/M4-RELEASE-AUDIT.md`)**:
  - Formally audited exit gate report confirming clean-machine installation, open/edit/autosave/recover/export/update/uninstall capabilities, least-privilege permissions, and cross-platform typography rendering tolerances.
