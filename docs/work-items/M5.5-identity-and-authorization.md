# Work Item: M5.5 Collaborative Identity, Authorization & Room Lifecycle

Status: Approved  
Milestone: M5 (Collaboration Preview)  
Owner: Core Architecture Team  

## User outcome

Secure multi-user authorization with owner/editor/viewer roles, cryptographically high-entropy expiring invitation tokens, token revocation, participant removal, room lifecycle management, document-version compatibility checks, and append-only security audit trails.

## Scope

### Included

- **Authorization Engine (`src/collaboration/authEngine.ts`)**:
  - Roles: `owner`, `editor`, `viewer`.
  - Cryptographically secure 256-bit high-entropy invitation token generator (`createInvitationToken`).
  - Expiring invitations and token revocation registry (`revokeInvitationToken`).
  - Participant removal & access ejection (`removeParticipant`).
  - Room lifecycle state machine (`created`, `active`, `archived`, `closed`).
  - Document-version compatibility checker (`validateDocumentVersionCompatibility`).
  - Append-only audit event logging (`getAuditTrail`).

## Verification

- Unit tests in `authEngine.test.ts`.
- `npm run check` pipeline execution.
