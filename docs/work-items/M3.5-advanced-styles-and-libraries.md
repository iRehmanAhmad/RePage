# Work Item: M3.5 Advanced Object Styles, Libraries & Conflict Resolution

Status: Approved  
Milestone: M3 (Document Production Beta)  
Owner: Core Architecture Team  

## User outcome

Users can define reusable Object Styles (fill, stroke, corner radius, opacity, shadow), organize Style Libraries, import style definitions from external `.urdup` documents with conflict resolution (`overwrite`, `keep-existing`, `rename`), and clean up unused document styles.

## Problem and evidence

Publishing houses require shared style libraries for book series and newspaper templates to maintain consistent object borders, fills, headlines, and poetry callout frames.

## Scope

### Included

- **Object Style Schema (`src/domain/rich-text/objectStyles.ts`)**:
  - `ObjectStyle` Zod schema and default Urdu object style presets.
- **Style Library & Import Engine (`src/domain/rich-text/styleLibrary.ts`)**:
  - `importStyles(targetStyles, sourceStyles, conflictStrategy)` for importing styles with conflict handling (`overwrite` | `keep-existing` | `rename`).
  - `cleanupUnusedStyles(doc)` to identify and remove unreferenced styles.
- **Unit Tests (`src/domain/rich-text/styleLibrary.test.ts`)**:
  - Verification of style library presets, import merge strategies, and unused style pruning.

### Excluded

- WebGL shader effects on strokes (deferred to M4).

## Acceptance criteria

- [x] Object styles validate under Zod schema.
- [x] `importStyles` resolves name/ID conflicts using `overwrite`, `keep-existing`, or `rename` strategies.
- [x] `cleanupUnusedStyles` removes unreferenced style definitions.
