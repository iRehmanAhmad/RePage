# Work Item: M5.4 Collaborative Networking & Connectivity Diagnostics

Status: Approved  
Milestone: M5 (Collaboration Preview)  
Owner: Core Architecture Team  

## User outcome

Resilient, real-time multi-user networking with production WebSocket signaling, WebRTC STUN/TURN ICE configuration, forced-relay fallback, automatic network reconnects, small-room limits (2–4 editors), and clear connectivity diagnostics.

## Scope

### Included

- **Network Provider Engine (`src/collaboration/networkProvider.ts`)**:
  - Production WebSocket signaling (`wss://signaling.repage.org`).
  - WebRTC STUN (`stun:stun.l.google.com:19302`) and TURN (`turn:turn.repage.org:3478`) server configuration.
  - Forced-relay mode (`iceTransportPolicy: 'relay'`).
  - Small-room editor limit (Max 4 editors per room).
  - Automatic reconnection logic with exponential backoff for network drops and IP interface shifts.
  - Connectivity diagnostics report (`getNetworkDiagnostics`).

## Verification

- Unit tests in `networkProvider.test.ts`.
