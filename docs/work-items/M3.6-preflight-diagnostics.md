# Work Item: M3.6 Pre-flight Verification & Urdu Document Diagnostics

Status: Approved  
Milestone: M3 (Document Production Beta)  
Owner: Core Architecture Team  

## User outcome

Automated Pre-flight verification engine and UI panel alerting users to missing fonts, overset text overflow frames, missing image assets, font license compliance flags, and document schema reference errors before export.

## Problem and evidence

Publishing errors (missing fonts, overset text cutoffs, unapproved licenses, missing linked image assets) must be detected automatically prior to print or PDF export.

## Scope

### Included

- **Pre-flight Diagnostics Engine (`src/domain/diagnostics/preflightEngine.ts`)**:
  - `runPreflightCheck(doc)` executing:
    1. Font availability & embedding license check.
    2. Overset text overflow detection.
    3. Image asset resolution & missing link detection.
    4. Canonical schema reference integrity check.
- **Pre-flight Panel UI (`src/ui/diagnostics/PreflightPanel.tsx`)**:
  - Filterable diagnostic issue listing with visual severity badges (`Error`, `Warning`, `Info`).
- **Unit Tests (`src/domain/diagnostics/preflightEngine.test.ts`)**:
  - Comprehensive preflight rule verification tests.

### Excluded

- Automatic PDF color space CMYK profile conversions (deferred to M3.7).

## Acceptance criteria

- [x] `runPreflightCheck` detects unregistered font usages as warnings/errors.
- [x] Overset text frames generate overflow warnings.
- [x] Missing asset references trigger error diagnostic reports.

## Verification

- Unit tests in `preflightEngine.test.ts`.
- `npm run check` pipeline execution.
