# Work Item: M2.3 Tiptap Editing Overlay for Fabric Text Frames

Status: Approved  
Milestone: M2 (Urdu Typography Beta)  
Owner: Core Architecture Team  

## User outcome

Users can double-click or select a text frame on the canvas to activate a rich-text DOM overlay powered by Tiptap/ProseMirror, type and format Urdu text with native RTL direction, and commit changes cleanly into canonical `TextStory` documents.

## Problem and evidence

Canvas-rendered text frames in Fabric.js do not provide full DOM accessibility, IME input handling, or rich-text selection. RePage requires a Tiptap DOM overlay synchronized with canvas coordinates.

## Scope

### Included

- Tiptap React editor overlay component (`TextEditorOverlay.tsx`).
- Positioning, scale, and rotation alignment over active `TextFrameObject`.
- Native `rtl` Urdu text direction and typography styles (`Noto Nastaliq Urdu`).
- Synchronizing edited text content back to canonical `TextStory` via domain commands.
- Focus transition between Fabric canvas selection and rich-text overlay.
- Unit tests for editor overlay synchronization.

### Excluded

- WebGL shader canvas rendering (deferred to export phase).

## Acceptance criteria

- [x] Selecting a text frame opens the Tiptap rich-text editing overlay.
- [x] Text edits in the overlay update canonical story content in `RePageDocument`.
- [x] Undo/redo (`Ctrl+Z`, `Ctrl+Y`) and autosave work across text editing operations.

## Verification

- Unit tests in `src/ui/editor/TextEditorOverlay.test.tsx`.
- `npm run check` pipeline execution.
