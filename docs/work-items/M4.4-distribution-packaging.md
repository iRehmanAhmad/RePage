# Work Item: M4.4 Distribution & Cross-Platform Packaging Pipeline

Status: Approved  
Milestone: M4 (Cross-Platform Desktop Release Candidate)  
Owner: Core Architecture Team  

## User outcome

Automated cross-platform installer production and distribution pipeline for Windows (NSIS), macOS (DMG/Notarization), and Linux (AppImage/DEB/RPM) with registered `.urdup` file associations, desktop launcher entries, and font dependencies.

## Scope

### Included

- **Tauri 2 Distribution Configuration (`src-tauri/tauri.conf.json`)**:
  - Windows NSIS installer with registry file association and Start menu shortcuts.
  - macOS bundle configuration with entitlements, notarization flags, and universal architecture support.
  - Linux AppImage, `.deb`, and `.rpm` targets with `webkit2gtk` and `fontconfig` dependency declarations.
- **Distribution Specification (`docs/DISTRIBUTION.md`)**:
  - Detailed cross-platform release, signing, notarization, and verification procedures.
- **CI/CD Build & Packaging Workflow (`.github/workflows/release-distribution.yml`)**:
  - Multi-platform GitHub Actions release workflow.
- **Distribution Verification Utility (`scripts/verify-distribution.js`)**:
  - Automated check for installer definitions, MIME types, and bundle integrity.
- **Unit Tests (`src/platform/distribution.test.ts`)**:
  - Manifest and distribution config verification tests.

## Verification

- Unit tests in `distribution.test.ts`.
- `npm run check` pipeline execution.
