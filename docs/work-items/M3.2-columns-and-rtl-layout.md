# Work Item: M3.2 Columns & RTL Column Layout Engine

Status: Approved  
Milestone: M3 (Document Production Beta)  
Owner: Core Architecture Team  

## User outcome

Text frames support multi-column layouts (`columns`, `columnGap`) with RTL column ordering (Right-to-Left column 1 \(\rightarrow\) 2 \(\rightarrow\) 3 for Urdu), top/middle/bottom vertical alignment, and visual column guide lines on the canvas.

## Problem and evidence

Urdu newspapers and magazines require multi-column text frames flowing right-to-left with consistent column gaps and vertical alignment options.

## Scope

### Included

- **Column Layout Engine (`src/domain/layout/columnEngine.ts`)**:
  - `computeColumnRects(width, height, padding, columns, gap, rtl)` for RTL column geometry.
  - `computeVerticalTextOffset(textHeight, height, padding, alignment)` for top, middle, bottom vertical alignment.
- **Domain & Schema Integration (`types.ts`, `schema.ts`)**:
  - Extended `TextFrameObject` with `verticalAlignment` (`top` | `middle` | `bottom`) and `rtlColumnOrder` (`boolean`).
- **Canvas Column Guides (`fabricAdapter.ts`)**:
  - Renders dashed column guide dividers inside multi-column text frames on the canvas.
- **Unit Tests (`src/domain/layout/columnEngine.test.ts`)**:
  - RTL column order math, gap calculation, and vertical alignment testing.

### Excluded

- Balance-last-page vertical justification algorithms (deferred to M3.9).

## Acceptance criteria

- [x] `computeColumnRects` calculates correct column positions for RTL layout order.
- [x] `verticalAlignment` ('top' | 'middle' | 'bottom') returns exact vertical offsets.
- [x] Multi-column frame definitions pass Zod schema validation.

## Verification
