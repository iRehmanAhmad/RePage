# Work Item: M2.6 Text Flow Foundations & Multi-Frame Linked Stories

Status: Approved  
Milestone: M2 (Urdu Typography Beta)  
Owner: Core Architecture Team  

## User outcome

Text stories can link across multiple text frames sequentially (`previousFrameId` \(\rightarrow\) `nextFrameId` chain). Overflowing frames visually flag an overflow indicator (`+`) without corrupting single-frame documents.

## Problem and evidence

Long Urdu articles (newspapers, magazines, books) span multiple columns and pages. RePage requires a multi-frame linked story model with overflow detection.

## Scope

### Included

- Update `TextFrameObject` schema in `types.ts` and `schema.ts` with optional flow properties (`sequenceIndex`, `nextFrameId`, `previousFrameId`, `overflow`).
- Multi-frame linking helpers in `src/domain/document/textFlow.ts`:
  - `linkTextFrames(doc, sourceId, targetId)`
  - `unlinkTextFrame(doc, frameId)`
  - `checkFrameOverflow(text, fontSize, lineHeight, width, height)`
  - `getStoryFramesInSequence(doc, storyId)`
- Visual overflow indicator badge in Fabric canvas renderer when `overflow === true`.
- Unit tests in `src/domain/document/textFlow.test.ts`.

### Excluded

- Dynamic text re-flow layout engine across pages (deferred to M3 page layout phase).

## Acceptance criteria

- [x] `TextFrameObject` schema validates linked sequence fields without breaking single-frame documents.
- [x] `linkTextFrames` creates bidirectional `nextFrameId` and `previousFrameId` pointers.
- [x] Overflowing content triggers visual overflow indicator flag (`overflow: true`).

## Verification

- Unit tests in `src/domain/document/textFlow.test.ts`.
- `npm run check` pipeline execution.
