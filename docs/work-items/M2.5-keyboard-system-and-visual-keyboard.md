# Work Item: M2.5 Urdu Keyboard System & Visual On-Screen Keyboard

Status: Approved  
Milestone: M2 (Urdu Typography Beta)  
Owner: Core Architecture Team  

## User outcome

Users can type Urdu using CRULP Phonetic, Navees Phonetic, Native OS/IME, or English input modes, and insert specialized Urdu characters (ZWNJ, ZWJ, RLM, LRM, honorifics) via an interactive visual on-screen keyboard.

## Problem and evidence

Many desktop users do not have native Urdu hardware keyboards or system IME installed. RePage requires built-in phonetic keyboard layouts and an on-screen visual keyboard.

## Scope

### Included

- Phonetic layout mappings in `src/domain/unicode/keyboardLayouts.ts` (CRULP Phonetic and Navees Phonetic layouts).
- Interactive visual keyboard component `VisualKeyboard.tsx` with Shift layer and special control buttons (ZWNJ, ZWJ, RLM, LRM, honorifics).
- Input mode selector in `App.tsx` (CRULP, Navees, Native OS, English).
- Unit tests in `src/domain/unicode/keyboardLayouts.test.ts` and `src/ui/keyboard/VisualKeyboard.test.tsx`.

### Excluded

- Operating-system level kernel keyboard driver installation.

## Acceptance criteria

- [x] CRULP Phonetic and Navees Phonetic key mappings map QWERTY keys to corresponding Urdu characters.
- [x] Shift layer toggles uppercase/alternate character mappings.
- [x] Visual keyboard renders and inserts special characters (ZWNJ, ZWJ, RLM, LRM, honorifics).

## Verification

- Unit tests in `src/domain/unicode/keyboardLayouts.test.ts` and `src/ui/keyboard/VisualKeyboard.test.tsx`.
- `npm run check` pipeline execution.
