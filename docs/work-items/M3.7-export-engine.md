# Work Item: M3.7 Vector PDF Metadata & Standalone SVG Export Engine

Status: Approved  
Milestone: M3 (Document Production Beta)  
Owner: Core Architecture Team  

## User outcome

Standalone export engine operating independently of the interactive canvas viewport to produce scalable SVG vector markup, print marks (crop lines, bleed bounds, registration targets), and compliant PDF metadata with Urdu locale attributes (`ur-PK`).

## Problem and evidence

Publishing output must not rely on screenshot/raster canvas captures. Exporting requires standalone vector rendering outside Fabric for true PDF/SVG output with print prepress marks.

## Scope

### Included

- **Standalone Export Engine (`src/export/exportEngine.ts`)**:
  - `exportDocumentToSvg(doc, pageId)`: Standalone DOM/string SVG vector renderer for pages and objects.
  - `exportDocumentToPdfMetadata(doc)`: Produces PDF info dictionary with `ur-PK` language and metadata.
  - `computePrintMarks(pageWidth, pageHeight, bleed)`: Calculates crop mark and bleed vector paths.
- **Unit Tests (`src/export/exportEngine.test.ts`)**:
  - Verification of standalone SVG rendering, PDF catalog metadata, and crop mark geometry calculations.

### Excluded

- WebAssembly PDF/X-1a prepress compiler (deferred to M4).

## Acceptance criteria

- [x] `exportDocumentToSvg` produces valid SVG vector markup containing text and geometric objects.
- [x] `exportDocumentToPdfMetadata` returns `ur-PK` metadata dictionary.
- [x] `computePrintMarks` generates crop and bleed lines outside margins.

## Verification

- Unit tests in `exportEngine.test.ts`.
- `npm run check` pipeline execution.
